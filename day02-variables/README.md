## Data Types

| Type | Size | Example | QA Use |
|------|------|---------|--------|
| int | 4 bytes | 25, 3582 | Bill numbers, quantity |
| double | 8 bytes | 500.50 | Prices, amounts |
| String | Varies | "Test Patient" | Names, status |
| boolean | 1 bit | true, false | Flags |
| char | 2 bytes | 'A', 'B' | Single characters |
